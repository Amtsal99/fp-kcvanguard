#  Real-time SIBI Translator using MediaPipe and BiLSTM

This project enables real-time translation of SIBI (Sistem Isyarat Bahasa Indonesia) using **MediaPipe** to extract hand landmarks and a **BiLSTM** model to classify sequences of hand gestures into meaningful words.

##  Features

- Real-time SIBI (sign language) gesture detection
- 3D hand landmarks tracking using [MediaPipe](https://mediapipe.dev/)
- Sequence-based recognition using BiLSTM
- Custom dataset support
- Extensible and lightweight
